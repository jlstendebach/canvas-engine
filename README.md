# Canvas Engine (working title)
An object-oriented, canvas-based graphics framework aimed a quick and easy development of custom graphics, simulations, and games.

# Usage
To target the latest version:
- `import { ... } from "https://cdn.jsdelivr.net/gh/jlstendebach/canvas-engine/index.js"`

To target a specific release:
- `import { ... } from "https://cdn.jsdelivr.net/gh/jlstendebach/canvas-engine@v0.1.0/index.js"`

If you have pulled the library, you can link to it directly:
- `import { ... } from "path/to/library/index.js"`

# Testing
This library uses [Jest](https://jestjs.io/) for testing. To test, run the following command: 
- `npm test`

# Running Locally
- Run command `npm install http-server`
- Navigate to the your project's repo
- Run command `http-server`
- Open `http://localhost:8080/` in your browser (port may be different based on config)

## Development Setup

This project has been migrated to TypeScript. It uses a highly efficient, lightweight configuration that relies strictly on the native TypeScript compiler (`tsc`) with zero bundling overhead, matching our browser-first architecture.

### 1. Installation

Install the required development dependencies:

```bash
npm install
```

### 2. Development Workflow

To develop locally, you will need to run the compiler and your local development server simultaneously.

#### Step A: Start the TypeScript Compiler (Terminal 1)
Run the TypeScript compiler in watch mode. It will silently watch your `src/` directory and compile your `.ts` files into standard `.js` files inside the `dist/` directory instantly on save:

```bash
npm run watch
```

#### Step B: Start the HTTP Server (Terminal 2)
In a separate terminal window, launch your local web server to view the canvas engine running in your browser:

```bash
npx http-server
```

Open the local URL provided by `http-server` (typically `http://localhost:8080`) to view your test pages.

### 3. Production Build

To compile a clean, optimized version of the library complete with autogenerated TypeScript declaration files (`.d.ts`) for distribution or CDN usage, run:

```bash
npm run build
```

The production-ready assets will be generated in the `/dist` directory.
